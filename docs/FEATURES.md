## 1. 창과 파일

창 하나에서 여러 파일을 엽니다. 아래쪽 파일 탭 대신 **오른쪽 그룹 패널**이 열린 파일을 보여 줍니다.

- **시작 화면:** 처음 켜면 새로 만들기(엑셀, Markdown, SQL, 텍스트, Word, 한글, 사이트 연결, 기타 파일), 열기, 최근 항목이 나옵니다.
- **파일 바꾸기:** 그룹 패널에서 파일을 누르거나, 제목 표시줄의 파일 이름(`› 보고서.xlsx ▾`)을 눌러 고릅니다.
- **단축키:** Ctrl+Tab · Ctrl+Shift+Tab으로 다음 · 이전 파일, Ctrl+F4로 닫기.
- **마우스 뒤로 · 앞으로 버튼:** 브라우저처럼 좀 전에 보던 파일로 오가고, 웹 페이지 위에서는 그 페이지의 이전 · 다음 페이지로 먼저 갑니다.
- **저장하지 않은 파일**은 `●`로 표시되고, 닫을 때 먼저 묻습니다.
- **엑셀 파일**에만 아래쪽에 시트 탭이 나오고, 다른 파일은 그만큼 넓게 보입니다.
- **다른 프로그램이 고친 파일**(편집기, AI 도구 등)은 몇 초 안에 지금 내용으로 다시 보입니다. 모눈에서 고치던 중이면 바로 바꾸지 않고 '다시 불러오기'로 묻습니다.
- **이미 켜진 모눈:** 탐색기에서 파일을 열면 새 창 대신 켜진 모눈에 열립니다.

### 그룹 패널

- 제목 표시줄의 `≡` 버튼으로 켜고 끕니다. 제목을 끌어 왼쪽이나 오른쪽에 붙이고, `⋯` › '레이어로 띄우기'로 파일 위에 띄울 수 있습니다.
- **숨기기:** 제목 줄의 숨기기 버튼을 누르면 창 가장자리에 초록색 손잡이만 남습니다. 손잡이에 마우스를 올리면 카드로 나오고, 핀을 누르면 다시 고정됩니다.
- **정렬:** 그룹 순서(직접 정한 순서 · 이름순 · 최근 사용순)와 파일 순서(직접 정한 순서 · 이름순 · 종류순)를 고릅니다. 이름순은 숫자를 값으로 비교합니다(`화면2`가 `화면10`보다 앞).
- **파일 줄 오른쪽 클릭:** 닫기, 다른 파일 모두 닫기, 모두 닫기, 전체 경로 복사, 폴더에서 보기, 폴더로 이동.
- **여러 파일 고르기:** 탐색기처럼 `Ctrl`+클릭으로 하나씩 더하거나 빼고, `Shift`+클릭으로 마지막에 누른 파일부터 누른 파일까지 고릅니다. 고른 파일 하나를 끌거나 오른쪽 클릭하면(폴더로 이동, 닫기, 그룹에서 빼기, 전체 경로 복사) 고른 파일 모두에 적용됩니다. 그냥 클릭하면 선택이 풀립니다.

## 2. 그룹 · 폴더 · 프로젝트

### 그룹

함께 작업하는 파일 묶음입니다. 제목 표시줄의 그룹 버튼(`기본 그룹 ▾`)이나 그룹 패널에서 바꿉니다.

- 그룹을 바꾸면 지금 파일들이 닫히고, 그 그룹의 파일이 **순서와 앞에 있던 파일까지 그대로** 다시 열립니다. 저장하지 않은 파일은 바꾸기 전에 한 번에 묻습니다.
- 그룹은 열린 파일을 따라갑니다. 파일을 닫으면 그룹에서도 빠지고, 모눈을 다시 켜면 마지막 그룹이 열립니다.
- 새 그룹은 그룹 패널 `+` › 새 그룹…으로 만듭니다. '열린 파일을 새 그룹으로 가져가기'를 고르면 파일을 그대로 둔 채 새 그룹이 됩니다.
- 그룹을 오른쪽 클릭하면 이름 바꾸기, 삭제(파일은 그대로), 위 · 아래로 이동, 다른 프로젝트로 보내기가 있습니다.
- 열지 못한 파일(옮겼거나 지운 파일, 암호 · DRM이 걸린 파일)은 그룹에서 빠지고 안내창에 나옵니다.
- **파일 찾기(Ctrl+Shift+R):** 이클립스의 Open Resource처럼 모든 그룹의 파일을 이름으로 찾습니다.
  - 이름의 어느 부분이든 찾고(대소문자 무관), 띄어 쓴 낱말은 모두 들어 있어야 합니다. `*`(아무 글자들) · `?`(아무 한 글자)를 쓰면 그 모양으로 시작하는 이름을 찾습니다.
  - 이름이 찾는 말로 시작하는 파일, 지금 그룹의 파일이 먼저 나옵니다. 오른쪽에 그룹과 폴더가 보입니다.
  - ↑ · ↓로 고르고 Enter(또는 두 번 클릭)를 누르면, 다른 그룹의 파일은 **그 그룹으로 바뀌면서 그 파일이 바로 앞에** 열립니다.

### 그룹 안의 폴더

파일이 많아지면 폴더로 나눕니다.

- 그룹 패널 `+` › 새 폴더…, 또는 그룹 · 폴더를 오른쪽 클릭 › 새 폴더…로 만듭니다(하위 폴더 가능).
- 파일을 폴더 위로 끌어다 놓거나, 오른쪽 클릭 › 폴더로 이동으로 옮깁니다. `Shift` · `Ctrl`로 여러 파일을 골라 한 번에 옮길 수도 있습니다.
- 폴더를 지우면 안에 있던 것들이 한 단계 위로 나옵니다. 파일 자체는 그대로입니다.
- 저장한 적 없는 새 파일도 폴더에 넣을 수 있고, 다른 이름으로 저장해도 같은 폴더에 남습니다.
- 폴더 설정에는 [API 요청](#7-api-요청)이 쓰는 변수와 공통 헤더를 넣습니다.

### 프로젝트

그룹 위의 묶음입니다. 문서 폴더를 git으로 여러 PC에서 함께 쓸 때 씁니다.

- **작업 루트 폴더:** 파일 › 옵션 › 일반, 또는 프로젝트 메뉴(제목 표시줄의 `이 PC ▾`)에서 정합니다.
- **저장 위치:** 루트 폴더의 `.monun\<프로젝트>.json`. 파일은 루트 기준 상대경로(`주문/설계.md`)로 적히므로, 다른 PC에서 저장소를 받고 루트 폴더만 정하면 같은 그룹이 열립니다.
- **PC마다 따로인 것:** 앞에 있던 파일, 최근 사용 시각, 정렬, 폴더 접힘. 이것들만 바뀌어서는 git에 변경이 생기지 않습니다.
- **바깥에서 바뀐 프로젝트 파일**(git pull, 스크립트)은 몇 초 안에 반영됩니다. 쓰고 있는 그룹에 새로 들어온 파일은 탭으로 열리고, 모눈에서 닫은 파일은 다시 들어오지 않습니다. 바로 읽으려면 '프로젝트 다시 읽기'를 누릅니다.
- **이 PC:** 프로젝트를 쓰기 전부터 있던 그룹입니다. 이 PC에만 저장됩니다.
- 프로젝트를 지우면 `.json`만 지워지고 문서는 그대로입니다.

## 3. 메모 패널

제목 표시줄의 말풍선 버튼으로 켭니다(그룹 패널 자리에 나옵니다).

- **엑셀:** 시트의 셀 메모가 나옵니다.
- **Markdown:** 보기 화면에서 문단 · 목록 · 표 · 그림을 오른쪽 클릭 › '메모 추가'로 답니다. 문서 왼쪽 여백에 표시가 생기고, 패널에서 고치고 지웁니다.
- 메모는 .md 파일 안이 아니라 따로 저장되므로 **산출물 문서에는 아무것도 남지 않습니다.** 문서를 고쳐도 메모는 그 문단을 따라갑니다.
- 작업 루트 안 문서의 메모는 `.monun\memos\memos.json`에 저장되어 git으로 다른 PC에 따라갑니다. 루트 밖 문서의 메모는 이 PC의 설정에 저장됩니다.
- 패널 아래쪽 '그룹의 다른 파일'에 지금 그룹의 다른 파일 메모가 나오고, 누르면 그 위치로 갑니다.
- **파일 링크:** Markdown 문단을 오른쪽 클릭 › '파일 링크 추가…'로 그룹의 다른 파일(또는 '찾아보기…'로 고른 파일)을 문단에 연결합니다.
  - 문서 왼쪽 여백에 그 파일 이름이 표시되고, 누르면 그 파일이 열립니다. **마우스의 뒤로 버튼**을 누르면 문서로 돌아오므로 설명하거나 테스트할 때 문서와 SQL · API 요청 · 엑셀을 오가기 좋습니다.
  - 메모처럼 .md 밖에 저장되고 문단을 따라갑니다. 링크를 오른쪽 클릭하면 열기 · 전체 경로 복사 · 링크 삭제가 있고, 메모 패널에도 나옵니다.
  - 작업 루트 안의 링크는 루트 기준 경로로 저장되어 다른 PC에서도 맞는 파일을 엽니다. 1.1.6까지의 모눈은 링크가 든 `memos.json`을 읽지 않고 그대로 둡니다(업데이트하면 보입니다).

## 4. 엑셀 파일

- **형식:** XLSX를 그대로 열고 저장합니다. CSV/TSV, 예전 `.xls`(값과 수식), `.xlsb` · `.ods`(데이터)를 읽습니다.
- **한글 CSV:** 엑셀이 쓰는 CP949(ANSI) CSV를 알아보고, 읽은 인코딩 그대로 저장합니다. 다른 이름으로 저장에서 `CSV UTF-8`도 고를 수 있습니다.
- **수식:** 500개 이상의 함수, 동적 배열, LET · LAMBDA, 구조적 표 참조.
- **서식과 분석:** 조건부 서식, 표, 차트, 스파크라인, 피벗 테이블, 인쇄와 PDF 내보내기.
- **한국 업무**
  - `NUMBERSTRING`으로 한글 금액: `="일금 "&NUMBERSTRING(A1,1)&"원정"`. 셀 서식 `[DBNum4]General`도 같은 모양입니다.
  - 한국어 날짜 서식(`aaa` · `aaaa`, `[$-412]`, `[$-F800]`)과 `DATESTRING` 함수.
  - 수식 › 날짜 및 시간 › '한국 공휴일 넣기': 2025~2027년 관공서 공휴일을 시트와 이름으로 넣어 `WORKDAY` 등에 씁니다. 파일 안에 들어가므로 엑셀에서도 그대로 계산됩니다.
- **구매목록 서식:** 새로 만들기의 '구매목록'은 대상 · 금액을 적으면 첫 행에 총합계가 나오는 표입니다.

## 5. Markdown 문서

- **화면:** 도구줄의 편집 · 나란히 · 보기로 원문만, 원문과 미리보기를 좌우로, 완성된 문서만 봅니다. 화면 모드, 배율, 읽던 위치는 파일마다 기억합니다.
- **할 일 상자**(`- [ ]`)는 눌러서 체크합니다.
- **코드 블록**은 적힌 언어에 맞게 색이 칠해지고(SQL, Java, JavaScript, Python, JSON, XML, YAML, 셸 등), 오른쪽 위 버튼으로 그대로 복사합니다.
- **Mermaid 다이어그램:** ```` ```mermaid ```` 블록이 순서도 · 시퀀스 · 간트 · 마인드맵 등으로 그려집니다. 그림 오른쪽 위 버튼으로 따로 된 창에서 크게 봅니다.
  - 글상자 · 화살표 글자의 `<b>` · `<strong>`(굵게), `<i>` · `<em>`(기울임), `<u>`(밑줄), `<s>` · `<del>`(취소선), `<br>` · `<br/>`(줄바꿈)는 Mermaid처럼 그 모양으로 보입니다. `<span>` · `<font>` 같은 다른 태그는 글자만 남고, `List<Dto>`처럼 태그가 아닌 것은 그대로 보입니다.
- **HTML 섞어 쓰기:** `<br>`, `<b>`, `<mark>`, `<img>`, `<details>`, `<table>` 등이 GitHub처럼 그 모양으로 보입니다.
- **그림 넣기:** '그림' 버튼이나 Ctrl+V. 저장하면 .md 옆 `파일이름.assets` 폴더에 PNG · JPEG로 저장되어 다른 편집기에서도 보입니다.
- **찾기와 목차:** Ctrl+F · Ctrl+H로 찾고 바꾸고, '목차'로 제목 목록을 띄웁니다. Ctrl+휠로 확대합니다.
- **인쇄 · PDF**도 문서 모양 그대로 나옵니다.

## 6. SQL · 텍스트 · 소스 파일

`.sql`, `.txt`, 그리고 개발에 쓰는 소스 파일을 열어 고칩니다. **AI가 고친 파일만 프로젝트 그룹에 넣어 두고 바로 확인**하는 데 쓰기 좋습니다.

| 종류 | 확장자 |
|---|---|
| 백엔드 | Java, JSP, Kotlin, Groovy · Gradle, Scala, Python, C · C++ · C#, Go, Rust, PHP |
| 프런트엔드 | JavaScript · TypeScript(JSX · TSX), Vue, Svelte, CSS · SCSS · Less |
| 설정 · 데이터 | XML(MyBatis 매퍼, XSD, WSDL), JSON, YAML, TOML, INI, properties, `.env` |
| 스크립트 · 기타 | Shell, 배치, PowerShell, FreeMarker, Velocity, Diff, 로그, `Dockerfile`, `Makefile`, `.gitignore` |

- **색:** 확장자에 맞게 칠해집니다. Vue · JSP · HTML 안의 `<script>`는 JavaScript, `<style>`은 CSS, JSP의 `<% %>`는 Java로 칠합니다. SQL은 Oracle · PostgreSQL · MySQL · SQL Server의 낱말과 바인드 변수(`#{id}`, `:name`)까지 구분합니다.
- **표시:** 상태 표시줄에 언어(Java, Vue, YAML…), 인코딩, 줄바꿈이 나오고 왼쪽에 줄 번호가 붙습니다.
- **편집:** Enter는 윗줄 들여쓰기를 잇고, Tab · Shift+Tab은 고른 줄을 들여쓰고 내어씁니다. Ctrl+F · Ctrl+H로 찾고 바꿉니다.
- **저장:** 연 그대로의 인코딩(UTF-8, BOM 있는 UTF-8, 예전 한글 EUC-KR/CP949)과 줄바꿈(CRLF/LF)으로 저장합니다.
- **새 파일:** 종류마다 메뉴를 두지 않고 **새 기타 파일…** 하나로 만듭니다(시작 화면, 파일 › 새로 만들기, 그룹 패널 `+`, 폴더 오른쪽 클릭). 이름을 확장자까지 넣으면(`Main.java`, `application.yml`) 그 종류가 됩니다.
- `.json`은 모눈 통합 문서 형식이 아니면 소스로 열립니다. `.html`은 웹 페이지로 보입니다.
- 탐색기의 '연결 프로그램'에 .java, .jsp, .js, .ts, .vue, .xml, .yml, .properties, .json, .css, .gradle, .kt, .py, .log 등이 들어갑니다(기본 앱은 바꾸지 않습니다).

## 7. API 요청

Postman처럼 API를 보내고 응답을 봅니다. 요청은 `.http` 파일(VS Code REST Client · IntelliJ HTTP Client와 같은 형식)로 저장되어 다른 도구로도 읽힙니다.

- **만들기:** 그룹 패널 `+` › 새 API 요청(폴더를 오른쪽 클릭하면 그 폴더에), 또는 파일 › 새로 만들기 › API 요청.
- **요청:** 메서드 · 주소, 파라미터(표), 헤더, 본문을 고치고 **보내기(Ctrl+Enter)**. 보내는 동안 화면은 멈추지 않고 취소할 수 있습니다. 파일 하나에 요청이 여러 개면 왼쪽 목록에서 고릅니다.
  - 처음 열 때 본문이 있는 요청은 본문 탭이, 없는 요청은 파라미터 탭이 보입니다. 탭을 직접 고르면 그 탭이 유지됩니다.
  - 요청 칸은 내용만큼의 높이여서 응답이 바로 아래에 붙습니다(길면 화면의 60%까지 늘고 스크롤). 사이의 선을 끌면 높이를 정하고, 두 번 클릭하면 다시 내용에 맞춥니다.
- **본문:** none · form-data · x-www-form-urlencoded · raw(Text · JavaScript · JSON · HTML · XML) · binary · GraphQL. JSON · XML은 '정렬'로 들여씁니다.
- **응답:** 상태 · 걸린 시간 · 크기, 본문과 헤더. 본문은 JSON · XML · HTML · Text로 색을 입히고 정렬해 보여 줍니다('원본 그대로'도 가능).
- **폴더의 변수와 공통 헤더:** 폴더 오른쪽 클릭 › 폴더 설정…에서 변수(`Domain`, `Token` 등)와 공통 헤더(`Authorization: Bearer {{Token}}`)를 정합니다.
  - 주소 · 헤더 · 본문에 `https://{{Domain}}/api/v1/orders/{{OrderNo}}`처럼 쓰면 값으로 바뀝니다.
  - 하위 폴더는 위 폴더의 값을 물려받고, 가까운 폴더 → 파일의 `@이름 = 값` → 요청 안의 값 순서로 우선합니다.
  - 주소 · 파라미터 · 헤더 · 본문에 쓴 `{{변수}}`는 색으로 표시됩니다. 값이 있으면 초록 글자에 연한 초록 바탕, 값이 없으면 빨간 글자에 연한 빨간 바탕입니다.
  - 값이 없는 변수는 빨갛게 알리고 보내지 않습니다. `{{$timestamp}}`, `{{$isoTimestamp}}`도 씁니다.
  - '숨김' 값은 화면에서만 가려지고 파일에는 그대로 저장됩니다. git으로 공유하는 프로젝트에 토큰을 넣을 때 주의하세요.
  - **사용:** 변수마다 '사용' 체크가 있어 같은 이름의 변수를 여러 개 두고 그중 하나를 골라 씁니다(예: `BSNS_NO`를 값별로 두고 바꿔 가며 보내기).
    - 새 변수는 '사용'으로 체크되어 들어갑니다. 이미 사용 중인 변수와 이름이 같으면 새로 넣은 쪽이 해제됩니다.
    - 해제된 변수를 체크하면 같은 이름의 다른 변수는 해제됩니다. 이름마다 하나만 사용됩니다.
    - 해제된 변수는 흐리게 보이고, 요청은 읽지 않습니다. 같은 이름의 변수가 모두 해제되면 `{{이름}}`은 값이 없는 변수(빨강)가 됩니다.
- **환경(개발 · 로컬 · 운영):** Postman의 환경처럼 같은 요청을 환경마다 다른 값으로 보냅니다.
  - 폴더 설정…의 **환경**에서 '환경 추가'를 누르면 개발 · 로컬 · 운영 순서로 이름이 들어갑니다(이름은 바꿀 수 있습니다). 변수 표에 환경마다 값 칸이 생기고, 비워 둔 칸은 '값' 칸을 씁니다.
  - 요청 줄 맨 앞(메서드 앞)의 환경 상자에서 환경을 고르면 `{{url}}` 같은 변수가 그 환경의 값으로 바뀝니다. 바로 아래 `→` 줄에 실제로 갈 주소가 보입니다.
  - 고른 환경은 그룹의 모든 요청에 똑같이 적용됩니다. PC마다 따로 기억하므로 환경을 바꿔도 프로젝트 파일(git)은 바뀌지 않습니다.
- **회사망:** 인증서는 Windows 인증서 저장소로 검사하므로 회사 인증서가 있어도 브라우저처럼 통합니다. 자체 서명 인증서는 폴더 설정의 '인증서를 검사하지 않음'으로, 프록시는 `HTTPS_PROXY` · `HTTP_PROXY` 환경 변수로 지정합니다.

## 8. Word 문서

- `.docx`를 열어 읽고 고칩니다. `.doc` · `.rtf` · `.odt`도 열리고 `.docx`로 저장합니다.
- 처음에는 **보기**로 열리고, 도구줄의 **편집**을 눌러야 고칩니다(원본이 실수로 바뀌지 않게).
- 보기: 쪽 연속 스크롤, 너비 맞춤 · 확대, 한 쪽 · 두 쪽, 쪽 이동, 목차, 찾기, 글자 복사.
- 편집: 한글 입력, Word 단축키, 실행 취소, 서식 유지 복사 · 붙여넣기, 바꾸기. 스타일 · 글꼴 · 크기 · 굵게 · 글자색 · 형광펜 · 정렬 · 목록 · 들여쓰기 · 표.
- 저장(Ctrl+S), PDF 내보내기, 인쇄. 맞춤법 검사는 없습니다.
- 특수한 Word 요소는 저장할 때 빠질 수 있으니, 복잡한 양식은 사본으로 고치세요.

## 9. 한글 문서

- `.hwp` · `.hwpx`를 열어 읽고 고칩니다. 연 형식 그대로 저장하고, 새 문서는 `.hwpx`로 만듭니다.
- 처음에는 **보기**로 열리고, **편집**을 눌러야 고칩니다.
- 보기: 표 · 수식 · 그림 · 다단 · 머리말 · 각주가 그대로 보이고, 목차 · 찾기 · 글자 복사가 됩니다.
- 편집: 본문과 표 칸 입력, 실행 취소, 바꾸기. 글꼴 · 크기 · 굵게 · 글자색 · 정렬 · 표 편집.
- 저장하면 빠지는 내용이 있으면 원본을 덮어쓰지 않고 알려 줍니다(다른 이름으로 저장).
- 인쇄는 화면과 같은 쪽을 300dpi로 보냅니다. PDF가 필요하면 인쇄에서 'Microsoft Print to PDF'를 고릅니다.
- 그림 · 도형 넣기, 변경 추적, 메모 · 각주 편집, 매크로는 없습니다.

## 10. 보기 전용 파일: PDF · 그림 · PowerPoint · 웹 페이지

| 종류 | 할 수 있는 것 |
|---|---|
| **PDF** | 쪽 연속 스크롤, 너비 맞춤 · 확대, 한 쪽 · 두 쪽, 목차(책갈피), 찾기, 글자 선택 · 복사. 파일마다 마지막 쪽과 배율을 기억합니다. 암호가 걸린 PDF는 열지 못합니다 |
| **그림** | .png · .jpg · .gif · .bmp · .webp · .ico · .tif. 창에 맞춰 보기, 실제 크기, 확대 · 축소 |
| **PowerPoint** | .pptx · .ppsx · .potx · .pptm 슬라이드를 위에서 아래로 넘겨 봅니다. 차트는 제목만, EMF · WMF 그림과 동영상은 보이지 않습니다. '기본 앱에서 열기'로 PowerPoint에서 엽니다 |
| **웹 페이지 · 사이트 연결** | .html · .htm과 사이트 연결(.url)을 Edge 웹 보기(WebView2)로 봅니다. 로그인 · 스크립트가 Edge와 같이 동작하고, 연결은 .url 파일이라 그룹과 프로젝트에 넣을 수 있습니다 |

- 그룹과 프로젝트에는 다른 파일처럼 들어갑니다.
- 바깥에서 바뀐 HTML · PowerPoint 파일은 다시 읽어 보여 줍니다.

## 11. 화면과 설정

- **한국어 화면:** 메뉴와 대화상자가 한국어이고, 설치된 한글 글꼴을 한글 이름으로 고릅니다.
- **엑셀과 같은 크기:** 100% 배율이 윈도우 엑셀과 같은 셀 크기입니다. 리본은 Ctrl+F1로 숨깁니다.
- **기본값:** 새 통합 문서는 D2Coding 11, 칸 너비 130px. [D2Coding](https://github.com/naver/d2codingfont)은 네이버가 무료로 배포하는 글꼴로, 모눈에 들어 있지 않으니 따로 설치하세요. 없으면 다른 글꼴로 대신 보입니다. 바꾸려면 `%APPDATA%\Monun\prefs.json`의 `defaultFont` · `defaultColumnWidth`를 고칩니다.
- **옵션:** 파일 › 옵션에서 테마(밝게 · 어둡게 · 시스템), 강조 색, 언어, 수식 입력줄, 자동 완성, 자동 저장, 계산 방식, 작업 루트 폴더, 업데이트를 정합니다.
- **업데이트(설치한 모눈):** NanoGit처럼 GitHub 릴리스에서 스스로 새 버전을 받습니다.
  - 켠 뒤 15초, 그다음 6시간마다 새 버전을 확인하고, 있으면 알림줄에 '모눈 x.y.z이(가) 나왔습니다 [업데이트…]'가 뜹니다. 파일 › 옵션 › 일반의 '새 버전 자동 확인'으로 끄고, '업데이트 확인'으로 바로 확인합니다.
  - '지금 업데이트'를 누르면 설치 파일을 받아 SHA-256을 확인하고, 모눈을 닫으며(저장하지 않은 파일은 먼저 묻습니다) 설치합니다. 설치가 끝나면 다시 켜져 '모눈을 x에서 y(으)로 업데이트했습니다'를 알립니다. 저장 질문에서 취소하면 업데이트는 기다립니다.
  - 바탕화면의 **'모눈 업데이트'** 바로가기(설치할 때 만들어짐)를 누르면 묻지 않고 바로 받아서 설치합니다. 모눈이 켜져 있으면 그 모눈이 업데이트합니다.
  - 소스에서 빌드한 모눈은 스스로 업데이트하지 않습니다(저장소의 `update.cmd`로 업데이트).
- **한글 표시:** 한글과 영문이 같은 기준선에 놓이고, 굵은 글꼴이 없는 글꼴(굴림체 등)도 굵게 보입니다.
- **문서 보안(DRM):** DRM이 걸린 파일은 열 수 없습니다. 보안 프로그램이 허용한 프로그램(엑셀 등)에서만 풀리기 때문이며, 모눈은 이를 우회하지 않습니다.

## 12. 자동 복구와 설정 파일

- **자동 복구:** 저장하지 않은 변경이 있으면 10분마다 `%APPDATA%\Monun\recovery`에 사본을 씁니다. 비정상 종료 뒤 다시 켜면 '제목 (복구됨)'으로 열어 줍니다.
- **설정과 로그:** `%APPDATA%\Monun`(`prefs.json`, `ui.json`, `logs\monun.log`). 업데이트나 제거 때도 지우지 않습니다.
- **웹 보기의 로그인 · 쿠키:** `%LOCALAPPDATA%\Monun\WebView2`.
