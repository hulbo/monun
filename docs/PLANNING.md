# 모눈 기획서

## 1. 배경

개발과 문서 작업을 하는 하루에는 프로그램이 많이 필요합니다. 엑셀로 표를 정리하고, 메모장이나 편집기로 SQL과 설정 파일을 보고, Postman으로 API를 확인하고, Word · 한글 · PDF로 산출물을 읽습니다. 업무가 바뀔 때마다 이 창들을 다시 찾아 여는 일이 반복됩니다.

모눈은 이 일을 **창 하나**로 모으려고 시작했습니다.

- 엑셀 파일을 엑셀처럼 열고 저장합니다.
- 업무에 필요한 문서 · 소스 · API 요청을 같은 창에서 엽니다.
- 업무 단위로 묶어 두었다가 한 번에 다시 엽니다.

개인 업무용으로 만들었고, 같은 일을 하는 동료들도 쓸 수 있도록 공개했습니다.

## 2. 목표

| 목표 | 내용 |
|---|---|
| **엑셀처럼** | XLSX를 그대로 열고 저장합니다. 셀 크기 · 단축키 · 함수 · 화면이 윈도우 엑셀과 같게 동작합니다. 모르는 내용도 지우지 않고 보존해 저장합니다 |
| **업무 단위로** | 파일을 그룹 · 폴더 · 프로젝트로 묶고, 그룹을 바꾸면 그 파일들이 그대로 다시 열립니다. 프로젝트는 문서 폴더에 저장되어 git으로 여러 PC가 함께 씁니다 |
| **한국 업무에 맞게** | 한국어 화면, 한글 금액(`NUMBERSTRING`), 한국어 날짜, 관공서 공휴일, CP949 CSV와 소스, 한글(.hwp/.hwpx) 문서 |
| **개발 업무에 맞게** | SQL과 소스 파일 편집, Postman 같은 API 요청, 바깥(AI 도구 등)에서 바뀐 파일의 자동 반영 |
| **가볍게** | 설치 파일 하나, 관리자 권한 없음, 인터넷 없이 동작, 설정은 내 PC에만 |

## 3. 원칙

1. **멈추지 않는다.** 어떤 파일을 열어도 프로그램이 죽지 않아야 합니다. 제품 코드는 패닉을 일으키는 코드를 쓰지 않고, 오류는 메시지로 알립니다.
2. **원본을 지킨다.** 저장하면 빠지는 내용이 있으면 원본을 덮어쓰지 않고 알립니다. 텍스트 파일은 연 인코딩 · 줄바꿈 그대로 저장합니다. Word · 한글 문서는 처음에 보기로 열립니다.
3. **남의 것을 넣지 않는다.** 다른 회사의 아이콘 · 그림 · 글꼴 · 서식 파일을 넣지 않고, 글꼴은 PC에 설치된 것을 씁니다.
4. **보안을 우회하지 않는다.** 문서 보안(DRM)이 걸린 파일은 열지 않으며, 다른 프로그램인 척하지 않습니다.
5. **사용자의 PC를 존중한다.** 기본 앱을 바꾸지 않고(연결 프로그램 목록에만 들어감), 설정은 업데이트 · 제거 때도 지우지 않습니다.

## 4. 설계

### 4.1 구조

순수 Rust로 만들었고, 층을 나눠 아래 층이 화면을 모르게 했습니다(자세한 구조는 [개발 가이드](DEVELOPMENT.md#저장소-구조)).

- **엔진**(`crates/engine`): 문서와 세션, 그리고 사용자가 하는 모든 동작을 **명령**으로 가집니다. 메뉴 · 단축키 · 매크로 기록 · 명령줄 도구 · AI 에이전트(MCP)가 모두 같은 명령을 씁니다.
- **화면**(`crates/ui-egui`): egui로 리본 · 그리드 · 패널 · 문서 화면을 그립니다. 데스크톱 앱과 웹 빌드가 같은 화면을 씁니다.

### 4.2 파일 종류

엔진은 스프레드시트와 텍스트 파일(Markdown, SQL, 소스, API 요청)을 직접 다룹니다. 그 밖의 형식은 문서 탭 하나로만 알고, 화면이 전용 라이브러리로 읽고 그립니다.

| 종류 | 다루는 방식 |
|---|---|
| 엑셀 · CSV | 엔진이 읽고 계산하고 저장 |
| Markdown · SQL · 텍스트 · 소스 · API 요청 | 엔진의 텍스트 문서. 이름(확장자)으로 종류와 색이 정해짐 |
| Word | WordCraft 엔진으로 읽고 고치고 저장 |
| 한글 | rhwp로 읽고 고치고 저장(문서마다 따로 된 스레드) |
| PDF | PdfCraft 렌더러로 보기 |
| PowerPoint · 웹 페이지 | HTML로 바꾸거나 그대로 Edge 웹 보기(WebView2)로 표시 |

### 4.3 그룹과 프로젝트

- **그룹**은 열린 파일을 따라갑니다. 파일을 열면 들어가고, 닫으면 빠집니다.
- **폴더**는 그룹 안에서 파일을 나눕니다. 저장한 적 없는 파일도 넣을 수 있습니다.
- **프로젝트**는 작업 루트 폴더의 `.monun\<이름>.json`에 그룹 · 폴더 · 파일을 루트 기준 상대경로로 적습니다.
  - git이 볼 변경은 그룹 · 파일 · 폴더 구성뿐입니다. 앞에 있던 파일, 정렬, 접힘 같은 것은 PC마다 따로 저장합니다.
  - 바깥(git pull, 자동화 스크립트)에서 바뀐 프로젝트 파일은 몇 초마다 확인합니다. 마지막으로 읽은 내용과 3-way로 비교해, 바깥에서 더한 파일은 받아들이고 모눈에서 닫은 파일은 되살리지 않습니다.

### 4.4 저장 위치

| 무엇 | 어디 |
|---|---|
| 설정 · 로그 | `%APPDATA%\Monun` (`prefs.json`, `ui.json`, `logs`) |
| 자동 복구 사본 | `%APPDATA%\Monun\recovery` |
| 프로젝트 · 루트의 메모 | `<작업 루트>\.monun` |
| 설치 위치 | `%LOCALAPPDATA%\Programs\Monun` |

## 5. 범위 밖

- 엑셀 VBA 매크로 실행(파일 안의 VBA는 보존만 합니다).
- 예전 `.ppt`, 암호가 걸린 PDF · PowerPoint.
- PowerPoint · PDF · 그림 편집.
- HTML 소스 편집(웹 페이지로 보기만 합니다).
- 맞춤법 검사.
